RedZone — ขึ้นโฮสต์ InfinityFree
====================================================

ในไฟล์ zip นี้มี 2 โฟลเดอร์

  htdocs/            = ลากขึ้นโฮสต์ (อัปโหลดของข้างในโฟลเดอร์นี้)
  นำเข้าฐานข้อมูล/    = 2 ไฟล์ SQL สำหรับ import ใน phpMyAdmin
                        (ห้ามอัปโหลดขึ้นโฮสต์ ใช้แค่ import)

ไฟล์นี้ (อ่านก่อน.txt) ก็ไม่ต้องอัปโหลด


ทำตามลำดับ 7 ขั้น
====================================================

ขั้น 1  สมัคร InfinityFree ให้เสร็จ จะได้ชื่อเว็บมา


ขั้น 2  สร้างฐานข้อมูล
        control panel -> MySQL Databases -> กดปุ่ม Create Database

        ★ ช่องชื่อให้พิมพ์แค่คำว่า   redzone
          ระบบจะเติมคำนำหน้าให้เอง กลายเป็น  if0_42862305_redzone

        ต้องพิมพ์ชื่อนี้เท่านั้น เพราะผมกรอกชื่อนี้ไว้ในไฟล์ให้แล้ว


ขั้น 3  นำเข้าข้อมูล
        control panel -> phpMyAdmin -> เลือกฐานข้อมูลที่สร้าง
        -> แท็บ Import -> เลือกไฟล์ -> Go

          ครั้งที่ 1   schema-hosting.sql
          ครั้งที่ 2   seed-hosting.sql

        ต้องเรียงลำดับนี้ ห้ามสลับ


ขั้น 4  ใส่รหัสผ่านฐานข้อมูล  (เหลือแค่ 1 บรรทัด)

        ค่า 3 อย่างกรอกไว้ให้แล้ว เหลือแค่รหัสผ่าน

        4.1  ในหน้า MySQL Databases กดรูป "ตา" ข้าง MYSQL PASSWORD
             เพื่อให้มันโชว์รหัส แล้วกดปุ่มคัดลอก

        4.2  เปิดไฟล์  htdocs/api/config/db.php  ด้วย Notepad หรือ VS Code
             หาบรรทัดที่ 6 ที่เขียนว่า

               define('DB_PASS', 'ใส่รหัสผ่าน MySQL ตรงนี้');

             ลบคำว่า  ใส่รหัสผ่าน MySQL ตรงนี้  ออก แล้ววางรหัสที่คัดลอกมาแทน
             ผลลัพธ์จะได้ประมาณ

               define('DB_PASS', 'aBc123XyZ');

             ระวัง 3 อย่าง
               - เครื่องหมาย ' ต้องเหลือครบทั้งหัวและท้าย
               - เครื่องหมาย ; ต้องอยู่ท้ายบรรทัด
               - ห้ามลบวงเล็บ )

        4.3  บันทึกไฟล์

        อีก 3 บรรทัดกรอกไว้ให้แล้ว ไม่ต้องแก้

               define('DB_HOST', 'sql311.infinityfree.com');
               define('DB_NAME', 'if0_42862305_redzone');
               define('DB_USER', 'if0_42862305');

        ★ ตอนสร้างฐานข้อมูลในขั้น 2 ต้องพิมพ์ชื่อว่า  redzone  เท่านั้น
          เพื่อให้ชื่อเต็มออกมาเป็น  if0_42862305_redzone  ตรงกับที่กรอกไว้
          ถ้าตั้งชื่ออื่น ต้องมาแก้บรรทัด DB_NAME ให้ตรงกับของจริง


ขั้น 5  อัปโหลด
        เอา "ของข้างในโฟลเดอร์ htdocs" ขึ้นไปไว้ในโฟลเดอร์ htdocs ของโฮสต์
        (ไม่ใช่ยกโฟลเดอร์ htdocs ขึ้นไปทั้งอัน ไม่งั้นจะกลายเป็น htdocs/htdocs)

        มี 33 ไฟล์ แนะนำใช้ FileZilla (ฟรี) จะเร็วและไม่หลุดกลางทาง
        ถ้าใช้ File Manager บนเว็บ ต้องเปิดให้เห็นไฟล์ที่ขึ้นต้นด้วยจุด
        (.htaccess) ด้วย ไม่งั้นจะตกไป 3 ไฟล์

        ไฟล์ที่ขึ้นต้นด้วยจุดและต้องมีบนโฮสต์ครบ 3 ไฟล์

          .htaccess
          api/config/.htaccess
          uploads/.htaccess


ขั้น 6  เปิดเว็บ ล็อกอิน

          ชื่อผู้ใช้   admin
          รหัสผ่าน    Rzf58f00!A84F

        ถ้าล็อกอินไม่ได้ ให้เช็กว่าต่อฐานข้อมูลติดไหม
        กด F12 -> แท็บ Console -> พิมพ์  RZ.LIVE  แล้ว Enter

          ได้ true   = ต่อฐานข้อมูลติด ถูกต้อง
          ได้ false  = ยังไม่ติด ให้ถ่ายรูปหน้าจอแท็บ Network ส่งมาถาม


ขั้น 7  ทำ 2 อย่างนี้ทันที (สำคัญ)

        7.1 เปลี่ยนรหัส admin
            รหัส Rzf58f00!A84F อยู่ในไฟล์นี้ ใครเห็นไฟล์ก็เข้าได้
            วิธีเปลี่ยนอยู่ใน docs/hosting.md หัวข้อ 4.1

        7.2 เปิด SSL / HTTPS ใน control panel
            ถ้าไม่เปิด รหัสผ่านที่คนกรอกจะวิ่งผ่านเน็ตเป็นข้อความเปล่า


สิ่งที่ห้ามอัปโหลดขึ้นโฮสต์
====================================================

  โฟลเดอร์ database/   มี hash รหัสผ่านของทุกบัญชี
  โฟลเดอร์ docs/       เอกสารภายใน
  README.md            มีโครงสร้างระบบทั้งหมด
  db.example.php       ตัดออกจาก zip นี้ให้แล้ว

ทั้งหมดนี้ไม่ได้อยู่ในโฟลเดอร์ htdocs ของ zip นี้ จึงไม่ต้องกังวล


ถ้าเว็บขึ้น 500 Internal Server Error ทั้งเว็บ
====================================================

  1. เปลี่ยนชื่อไฟล์ .htaccess (ตัวที่อยู่ชั้นนอกสุด) เป็น htaccess.txt
  2. รีเฟรชเว็บ
  3. ถ้าเว็บกลับมาได้ = ปัญหาอยู่ที่ไฟล์นั้น ให้แจ้งมาเพื่อแก้ให้ตรงกับโฮสต์
  4. ถ้ายัง 500 = ปัญหาอยู่ที่ค่าใน db.php ให้กลับไปเช็กขั้น 4
