2 · DFD Level 0

11 โพรเซส · Data Store D1 RedzoneDB · กระแสข้อมูล 48 เส้น ทุกเส้นมีชื่อข้อมูลกำกับ

3 · คำอธิบายโพรเซส

เลขชื่อโพรเซสความหมายหน้าที่ไฟล์จริง
1Registerสมัครสมาชิกตรวจชื่อผู้ใช้/รหัสนักศึกษาซ้ำ เข้ารหัสรหัสผ่าน แล้วบันทึกบัญชีใหม่register.php
2Loginเข้าสู่ระบบตรวจรหัสผ่าน อ่านบทบาทและสถานะบัญชี และนับจำนวนครั้งที่ล็อกอินผิด (ใช้ทั้ง User และ Admin)auth.php
3Report Incidentแจ้งเหตุการณ์รับข้อมูลเหตุ ตรวจพิกัดในรัศมี 4 กม. สร้างเลขรายงาน บันทึกรูปและสถานะแรกreports.php · upload.php
4View Mapดูแผนที่พื้นที่เสี่ยงดึงรายงานที่อนุมัติแล้วมาวางหมุด คำนวณระดับวงพื้นที่เสี่ยง และแสดงรายละเอียดพร้อมประวัติสถานะbootstrap.php · map.js
5Commentแสดงความคิดเห็นบันทึกความคิดเห็นใต้รายงาน และดึงเฉพาะที่ไม่ถูกซ่อนมาแสดงcomments.php
6Confirm Incidentยืนยันว่าพบเหตุตรวจว่าผู้ใช้เคยยืนยันรายงานนี้แล้วหรือยัง แล้วบันทึกการยืนยันและอัปเดตจำนวนreports.php (confirm)
7Review Reportตรวจสอบและอนุมัติผู้ดูแลอนุมัติให้ขึ้นแผนที่ หรือไม่อนุมัติพร้อมเหตุผลadmin.php (approve/reject)
8Resolve Reportดำเนินการและปิดเรื่องเปลี่ยนสถานะ บันทึกผลการแก้ไขและรูปหลังแก้ไขadmin.php (set_status/resolve)
9Notify Userแจ้งเตือนผู้ใช้สร้างการแจ้งเตือนเมื่อสถานะเปลี่ยน และนับจำนวนที่ยังไม่อ่านnotifications.php
10Ban Userระงับบัญชีผู้ใช้ระงับ/ปลดระงับบัญชีพร้อมเหตุผล และบันทึกลงประวัติการจัดการadmin.php (ban/unban)
11Remove Commentซ่อนความคิดเห็นตั้งค่าซ่อนความคิดเห็นที่ไม่เหมาะสมพร้อมเหตุผล (soft delete)admin.php (hide_comment)

5 · ผลตรวจตาม Table 6-2

กฎข้อกำหนดผลหลักฐาน
ANo process can have only outputs (miracle)ผ่านทุกโพรเซสมีข้อมูลเข้าอย่างน้อย 1 เส้น
BNo process can have only inputs (black hole)ผ่านทุกโพรเซสมีข้อมูลออกอย่างน้อย 1 เส้น
CA process has a verb-phrase labelผ่านRegister · Login · Report Incident · View Map · Comment · Confirm Incident · Review Report · Resolve Report · Notify User · Ban User · Remove Comment
DData cannot move from one data store to anotherผ่านมี Data Store เดียว และไม่มีเส้นเชื่อม store กับ store
EData cannot move from an outside source to a data storeผ่านทุกเส้นจาก User/Admin/OpenStreetMap เข้าโพรเซสก่อนเสมอ
FData cannot move to an outside sink from a data storeผ่านไม่มีเส้นจาก D1 ออกไปหา External Entity โดยตรง
GA data store has a noun-phrase labelผ่านD1 RedzoneDB
HData cannot move from a source to a sinkผ่านไม่มีเส้นระหว่าง User · Admin · OpenStreetMap
IA source/sink has a noun-phrase labelผ่านUser · Admin · OpenStreetMap
JA data flow has only one direction between symbolsผ่านอ่านและเขียนแยกเป็นคนละลูกศรเสมอ ไม่มีลูกศรสองหัว

6 · จุดที่แก้จากแผนภาพตัวอย่าง

ปัญหาในแผนภาพเดิมผิดกฎข้อไหน / เพราะอะไรแก้เป็น
“Redzone system” ถูกวาดเป็น External Entityตัวระบบเองเป็น External Entity ของตัวเองไม่ได้ ผิดนิยาม source/sink ที่ว่า “outside the system”ตัดออก งานที่กล่องนั้นทำถูกกระจายเป็นโพรเซส 7–9
มีเส้นเชื่อม “Redzone system” กับ D1 RedzoneDB โดยตรงผิดกฎ E และ F — Entity ต่อกับ Data Store ตรง ๆ ไม่ได้ทุกเส้นเข้า D1 ต้องผ่านโพรเซสก่อน
ไม่มีโพรเซส LoginAdmin และ User ต้องล็อกอิน แต่แผนภาพเดิมมีแค่ Registerเพิ่มโพรเซส 2 Login รับทั้ง User และ Admin
ไม่มีโพรเซสฝั่งตรวจสอบ/ปิดเรื่องมี Report incident แต่ไม่มีใครอนุมัติหรือปิดเรื่อง เส้น Report status ลอยอยู่เพิ่มโพรเซส 7 Review Report และ 8 Resolve Report
ไม่มีโพรเซสแจ้งเตือนระบบมีตาราง notifications แต่ไม่มีโพรเซสไหนสร้างหรืออ่านเพิ่มโพรเซส 9 Notify User
ไม่มีโพรเซสยืนยันเหตุฟีเจอร์ “ยืนยันว่าพบเหตุนี้” หายไปจากแผนภาพเพิ่มโพรเซส 6 Confirm Incident
เส้นหลายเส้นไม่มีคู่ตรงข้ามเช่น Comment context เข้า D1 แต่ไม่มีเส้นอ่านกลับออกมาแสดงใส่คู่อ่าน/เขียนให้ครบทุกโพรเซส
เส้นตัดกันหลายชั้นจนอ่านยากผิดหลักความอ่านง่ายจัดเป็นแถวละ 1 โพรเซส และวาด User/Admin/D1 ซ้ำพร้อมขีดคู่กำกับ ไม่มีเส้นตัดกันเลย
