## 5. กรณีทดสอบที่ต้องทดสอบด้วยมือบนระบบจริง

กรณีต่อไปนี้ไม่สามารถทดสอบอัตโนมัติบนเครื่องทดสอบได้ ต้องทดสอบด้วยมือบนเว็บโฮสต์จริง

| รหัส | กรณีทดสอบ | เหตุผล | วิธีทดสอบด้วยมือ |
|---|---|---|---|
| TC-SEC-05 | ไฟล์ .php ในโฟลเดอร์ uploads ต้องไม่ถูกประมวลผล | ทดสอบอัตโนมัติไม่ได้บนเครื่องทดสอบ เพราะใช้เว็บเซิร์ฟเวอร์ในตัวของ PHP ซึ่งไม่อ่านไฟล์ .htaccess (ผลที่วัดได้ HTTP 200 · โค้ดถูกรัน) ต้องทดสอบด้วยมือบนโฮสต์จริงที่ใช้ Apache | เรียกไฟล์ uploads/probe.php ผ่านเบราว์เซอร์ แล้วตรวจว่าเซิร์ฟเวอร์ต้องไม่รันโค้ด PHP (ตอบ 403 หรือส่งเป็นข้อความธรรมดา) |

## 6. ขอบเขตที่เอกสารนี้ยังไม่ครอบคลุม

รายการต่อไปนี้เป็นฟังก์ชันที่ยังไม่ได้พัฒนาในระบบ จึงยังไม่มีกรณีทดสอบ

| เรื่อง | สถานะ |
|---|---|
| การยืนยันตัวตนผ่านอีเมล | ยังไม่พัฒนา (เว็บโฮสต์ที่ใช้ปิดฟังก์ชันส่งอีเมล) |
| การรีเซ็ตรหัสผ่านด้วยตนเอง | ยังไม่พัฒนา ต้องให้ผู้ดูแลระบบแก้ไขในฐานข้อมูล |
| การแจ้งเตือนแบบผลักไปยังอุปกรณ์ | ยังไม่พัฒนา |
| การสำรองข้อมูลอัตโนมัติ | ยังไม่พัฒนา |
| การทดสอบภาระงาน (Load Test) | อยู่นอกขอบเขตของรายวิชา |

---

*เอกสารนี้สร้างจากผลการรันชุดทดสอบอัตโนมัติจริง ไม่ได้กรอกผลลัพธ์ด้วยมือ*
